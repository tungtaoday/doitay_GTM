## Mục tiêu
Tạo zero-click content — toàn bộ value nằm trong post, không cần navigate ra ngoài.

## Tại sao Zero-Click
- Algorithms ưu tiên content giữ users trên platform
- Users ngại click ra ngoài — friction kills engagement
- Build trust trước khi ask for click
- 80% content nên là zero-click, 20% có CTA link

## Zero-Click Formats

### Twitter
- Standalone tweet với full insight
- Thread với complete framework/tutorial
- Poll + analysis

### Instagram
- Carousel với full tutorial/framework (5-10 slides)
- Reel với complete tip/hack
- Infographic post

### Facebook
- Long-form post với complete story/lesson
- Video tutorial (full value, no "link in bio")
- Photo album với commentary

### LinkedIn
- Framework post (numbered list, complete)
- Story post (beginning→middle→end, lesson included)
- Data insight post (chart + analysis + takeaway)

## Structure
1. Hook (stop scroll)
2. Setup (why this matters)
3. Value delivery (complete, actionable)
4. Engagement trigger (question, poll, "save this")
5. Soft CTA only if relevant ("follow for more" not "click link")
